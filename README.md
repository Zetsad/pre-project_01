# หัวข้อ วิจัยที่ศึกษา

เรื่องที่1:Flood Hazard Mapping by Using Spatio-temporal Prediction Model

1.ข้อมูลอ้างอิง
คณะผู้วิจัย: Pornnapa Panyadee, Paskorn Champrasert , Somrawee Aramkul  และ Autanan Wannachai 

2.ปัญหาวิจัยที่ต้องแก้
ข้อมูลน้ำในพื้นที่ห่างไกลมีจำกัด: เนื่องจากสถานีโทรมาตร (Telemetry stations) ในพื้นที่ห่างไกลมีจำนวนน้อย ทำให้ข้อมูลอัตราการไหลของน้ำ (Water discharge) ไม่เพียงพอและ
แผนที่ความเสี่ยงน้ำท่วมแบบเดิมล่าช้า

3. วัตถุประสงค์ของงานวิจัย
เพื่อเสนอแบบจำลองการทำนายเชิงพื้นที่และเวลา (Spatio-temporal Prediction Model) เพื่อปรับปรุงกระบวนการสร้างแผนที่ความเสี่ยงภัยน้ำท่วม
เพื่อเพิ่มประสิทธิภาพในการตอบสนองต่อการเตรียมพร้อมรับมือน้ำท่วมและเพิ่มความแม่นยำของแผนที่ความเสี่ยง

4. วิธีการ/เครื่องมือ/โมเดล
จากงานวิจัยโมเดลที่มีประกอบด้วย 2 โมดูล ได้แก่:
โมดูลการทำนายเชิงเวลา (Temporal Prediction Module): ใช้เทคนิคการเรียนรู้เชิงลึกแบบ Long Short-Term Memory (LSTM) เพื่อทำนายอัตราการไหลของน้ำล่วงหน้า 
โมดูลการทำนายเชิงพื้นที่ (Spatial Prediction Module): ใช้เทคนิคการประมาณค่าในช่วงแบบ Inverse Distance Weighted (IDW) เพื่อสร้างข้อมูลพื้นผิวและประมาณค่าอัตราการไหลของน้ำรอบๆ พื้นที่ลุ่มน้ำ

5. ชุดข้อมูล/กลุ่มตัวอย่าง
พื้นที่ศึกษา: ลุ่มน้ำแม่ต๋ำ จังหวัดพะเยา ประเทศไทย ครอบคลุมพื้นที่ประมาณ 270 ตารางกิโลเมตร

6. ผลการศึกษา/จุดเด่น
ความแม่นยำในการทำนาย: โมเดล LSTM สามารถทำนายอัตราการไหลของน้ำล่วงหน้า 4 ชั่วโมงที่สถานีปลายน้ำได้โดยมีค่าความคลาดเคลื่อนเฉลี่ย (MAPE) เพียง 5.449% (ความแม่นยำประมาณ 95.26%)
ประสิทธิภาพของแผนที่: แผนที่ความเสี่ยงภัยน้ำท่วมที่สร้างขึ้นมีความแม่นยำถึง 96.7% เมื่อเทียบกับสถานการณ์น้ำท่วมจริง (กรณีศึกษาพายุเบบินคา)

7. ข้อจำกัด/ช่องว่างงานวิจัย
การพึ่งพาการประมาณค่า: ในพื้นที่ที่ไม่มีสถานีโทรมาตร ผู้วิจัยต้องใช้วิธีการประมาณค่า (Interpolation) จากสถานีใกล้เคียง ซึ่งความแม่นยำในการประมาณค่ายังคงเป็นประเด็นสำคัญที่มีผลต่อความถูกต้องของแผนที่
การกำหนดเวลาล่วงหน้า: การทำนายในงานวิจัยนี้อิงตามเวลาที่น้ำไหลจากต้นน้ำไปปลายน้ำ (ประมาณ 4 ชั่วโมง)
ซึ่งอาจเปลี่ยนแปลงได้ตามสภาพทางกายภาพอื่นๆ ที่ซับซ้อนกว่าเดิม



เรื่องที่ 2 :Real-Time Urban Flood Forecasting Systems for Southeast Asia—A Review of Present Modelling and Its Future Prospects

1. ข้อมูลอ้างอิง (Reference Citation)
ผู้แต่ง: Detchphol Chitwatkulsiri และ Hitoshi Miyamoto(ปี 2023)

2. ปัญหาวิจัยที่ต้องการแก้ (Research Problem)
เมืองใหญ่ในเขตร้อนของภูมิภาคเอเชียตะวันออกเฉียงใต้ (เช่น กรุงเทพฯ) เผชิญกับน้ำท่วมฉับพลันในเขตเมือง (Urban Flash Floods / Pluvial Flooding) ที่รุนแรงขึ้นจากภาวะโลกร้อน การขยายตัวของเมืองอย่างรวดเร็ว และระบบระบายน้ำที่รองรับไม่เพียงพอ

3. วัตถุประสงค์ของงานวิจัย (Research Objectives)
เพื่อทบทวนและสำรวจสถานะปัจจุบันของระบบพยากรณ์น้ำท่วมในเขตเมืองแบบ Real-time โดยมุ่งเน้น 3 องค์ประกอบหลัก: การพยากรณ์ฝน, แบบจำลองชลศาสตร์ และแบบจำลอง AI

4. วิธีการ/เครื่องมือ/โมเดลที่นำมาทบทวน(Methodology/Tools&ModelsReviewed)
ระบบตรวจวัดและพยากรณ์ฝนระยะสั้น (Rainfall Nowcasting)
แบบจำลองชลศาสตร์ตามกระบวนการฟิสิกส์ (Physical-Process-Based Hydraulic Models)
แบบจำลองปัญญาประดิษฐ์ที่ขับเคลื่อนด้วยข้อมูล (Data-Driven AI Models)

5. ชุดข้อมูล / กลุ่มตัวอย่างที่ศึกษา (Data / Environments Studied)
ข้อมูลการจัดการระบายน้ำและเรดาร์จริงในเอเชียตะวันออกเฉียงใต้ เช่น กทม. (กรุงเทพฯ), สิงคโปร์ และมาเลเซีย
การสำรวจแบบจำลองความสูงเชิงเลข (DEM / DSM) จากภาพถ่ายดาวเทียม, LiDAR และ UAV (โดรน) ที่ความละเอียดตั้งแต่ 0.1 ม. ถึง 50 ม.
ข้อมูลสถิติน้ำท่วมภาพถ่ายจากกล้องวงจรปิด (Surveillance Cameras > 12,000 ภาพ), ข้อมูล Crowdsourced และ Social Media

6. ผลการศึกษา / จุดเด่นของงาน (Key Findings & Highlights)
การพยากรณ์น้ำท่วมฉุกเฉินในเขตเมืองต้องการข้อมูลฝนจากเรดาร์ที่มีความละเอียดระดับ ≤ 1 กม. และคาบเวลาสั้น 5 นาที พร้อมทั้ง DEM ความละเอียดสูงประมาณ 5 เมตร ซึ่งเป็นค่าที่ให้ความแม่นยำต่อการประมวลผล
แบบจำลอง Deep Learning (โดยเฉพาะ CNN และ LSTM) สามารถแปลงข้อมูลมิติสูงให้ประมวลผลได้เร็วมาก ลดเวลาการคำนวณได้อย่างมีนัยสำคัญ ส่งผลให้ระบบได้ Lead Time ที่ยาวขึ้น เหมาะสำหรับการเตือนภัยแบบ Real-time

7. ข้อจำกัด / ช่องว่างงานวิจัย (Limitations & Research Gaps)
AI ขาดความยืดหยุ่นต่อการเปลี่ยนแปลงทางกายภาพ: โมเดล Data-driven AI ขาดความเข้าใจเชิงฟิสิกส์ หากเมืองมีการสร้างสิ่งก่อสร้างใหม่ ผังเมืองเปลี่ยน หรือสร้างท่อระบายน้ำใหม่ โมเดลจะไม่สามารถปรับตัวได้ทันที ต้องเทรนข้อมูลใหม่ทั้งหมด
